Forty-four avatars to replace the watermarked stock pictures: twenty generated by DiceBear and downloaded, twelve drawn for this game. The twelve at the top are the set for the game: six robots and six blobs, the same six colours in each. All are 256 x 256 PNG and already on disk.

Putting them in the game

  1. Copy the files you picked into Assets/Art/Avatars, keeping their names.
  2. In Unity select them and set Texture Type to Sprite (2D and UI).
  3. Drag them into PlayerProfileManager → Available Avatars, replacing the stock ones. The order there is the order on the Profile page.
  4. The Profile page highlights the selected one at 50% opacity, so avoid very dark art.
  5. For a CC BY 4.0 pick, add to the Créditos panel: Avatars by DiceBear, CC BY 4.0 plus the style's own author, listed at dicebear.com.
